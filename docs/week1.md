## 运行环境说明

本机使用 Python 3.11；当前可用的 PyTorch 是 CPU 版本。CUDA 安装包较大且当前网络较慢，若先用 CPU 训练，完整数据训练时长可能较长。小样本和完整数据的实验结果需要分开记录。小样本验证集只有 50 张，结果区间较宽，不能说明跨 SKU 泛化能力。
