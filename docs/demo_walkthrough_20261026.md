# AIE 视觉识别演示 · 客户版

## 如何使用

启动本机模型服务后，打开 `http://127.0.0.1:8765/#flow`。页面提供“流程演示”“任务记录”“演示设置”和“使用说明”。在“流程演示”选择一张现场图片，点击“开始分析”，即可从上传图片开始运行真实分析链路。

当前默认场景为包装分拣，识别包装件、箱体、袋装物与瓶子。原图支持 PNG/JPG，单张最大 15 MiB。可选上传同尺寸的 16 位单通道 PNG 深度图；深度当前仅保存，不计算物理尺寸。后台按已接入的可用模块执行，页面会提示材质分析是否已启用。

提交后页面查询真实任务进度，处理完成后自动打开本次结果。从上传开始的流程演示按五个步骤展开：

1. **查看原图**：了解本次分析的画面。
2. **识别物体**：把画面中的目标逐个圈出来，标出位置与轮廓。
3. **查看特写**：观察选定物体的近景图片。
4. **分析材质**：查看材质预测与各类别的模型评分。
5. **汇总与导出**：查看全部物体的结果表，以及供机器人上层系统读取的视觉感知数据，下载报告、图片和 JSON。

选择一个物体后，特写和材质分析会跟随同一个目标。“深度信息”作为可选补充查看；主流程在“汇总与导出”结束。投屏可使用“专注演示”。

回查历史任务时，在“任务记录”点击“查看”，会直接进入该任务的独立结果页（`#result/<job_id>`）。该页只展示当前任务的结果图片、目标数据和导出入口，并提供“返回任务记录”，不返回上传流程。这样可直接汇报某次分析成果，无需重新经过输入与分析步骤。

## 建议讲解顺序（约 3 分钟）

先上传一张现场图片，点击“开始分析”，展示实际任务进度。结果生成后，说明整张画面和检出物体总数，再选择一个物体，依次查看位置轮廓、特写和材质预测，最后打开汇总输出，解释上层系统能收到哪些数据。也可切换“原图分析”与“基于已有识别结果”的记录，说明两种结果来源。

“识别物体”在技术上称为检测与分割，表示区分每件物体的位置和轮廓。客户无需操作分割工具。

## 结果如何理解

- 点击“开始分析”会运行真实模型；切换结果步骤或查看历史记录不会重新运行模型。
- 材质是模型给出的预测，模型评分不等于实际准确率。客户页面集中展示预测内容与评分，原始 JSON 保留完整的处理信息。
- 示例检出 34 个目标；两侧设备区域有疑似误检，应结合画面复核，不把检出数量当作正确数量。
- 深度文件与状态已保留，物理尺寸、几何和物理属性尚未计算。
- 最后一步展示视觉感知数据的交接，不执行机械臂动作。

## 最终输出如何交给机器人系统

完整链路输出 `pipeline-1.0` 格式的 `result.json`，以及对应的图像、物体轮廓和报告。最后一页展示实际结果中的关键字段：

| 字段 | 含义与用途 |
| --- | --- |
| `instance_id` | 本次图片内的物体编号，关联该物体的所有结果 |
| `object_label` | 预测物体类别 |
| `bbox_xyxy` | 图像中的整数像素框 `[x1, y1, x2, y2]` |
| `mask_path` | 结果包内的二值轮廓图路径，用于定位物体覆盖的像素区域 |
| `material.top1_label` | 模型评分最高的材质类别 |
| `material.score` | 对应材质的模型评分 |

机器人上层系统可以读取这些视觉感知数据，关联目标位置、轮廓与材质预测。`mask_path` 是文件引用，需要与完整结果包中的图像文件一起使用。

这些数据还不是机械臂控制指令。像素框不等于机器人坐标系中的位置；当前尚未实现相机与机器人标定、三维抓取位姿计算和运动规划，也没有生成或发送关节角、末端轨迹或夹爪命令。深度像素处理及这些后续环节完成后，才可将感知结果进一步转换为可执行动作。

## 展示内容

默认展示中文名称、关键结果和必要说明。流程顶部只保留图片尺寸、物体数量、材质候选数量，去掉“结果状态”卡片。权重/图像 SHA-256、内部模型版本与绑定字段不在页面主内容显示。数据摘录也省略 SHA-256。技术附件入口默认隐藏，可在设置中开启；原始结果文件保留追溯信息。

任务记录展示后台返回的真实进度，支持手动刷新；已有成果通过“查看”进入独立任务结果页。在线版显示最近 100 条并标明总数；离线版显示已打包的成果。任务是否已结束与预测内容分开展示；部分模块未完成时保留已有成果并说明情况，不会用演示动画模拟任务正在处理。

演示设置可修改标题、默认记录，以及深度与技术附件入口。点击保存后标题与显示内容立即生效，默认记录在下次打开页面时使用；恢复默认也会保存。设置仅保存在当前浏览器，不跨设备同步、不修改后台模型参数。若浏览器拒绝本地存储，会明确提示保存失败。后台模块继续通过现有模块配置维护。

物体显示编号是当前记录内的顺序，不代表跨记录的同一物体；技术附件中保留原 instance_id。

双击演示包中的 `AIE3905_客户演示版.html` 可回看内嵌的真实成果并下载单个文件。离线版不能上传新图片或运行模型，页面会给出说明；新图片分析须使用已启动本机模型服务的在线页面。已打包任务的完整 ZIP 放在演示包的“完整结果”目录。界面精简不改变原始识别结果。
