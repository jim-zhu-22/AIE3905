# RGB-D Pipeline 基线与评估计划 v1

本计划对应八周项目的 Milestone 1。基线用于建立可重复的比较起点；候选方法在实际数据和运行环境验证前不写成既有结果。

## 1. 两周执行顺序

| 时段 | 工作 | 可验收产物 |
| --- | --- | --- |
| 第 1–2 天 | 核查现有审计记录、取得原始数据访问、确认深度单位/无效值/配准/相机参数和 SKU 来源 | 数据事实表、缺口清单；必要时重新运行 `scripts/inspect_rgbd.py` |
| 第 3–4 天 | 与数据/应用方审定几何、材质、形变标签和边界样例；确定 prompt 范围 | 冻结的 taxonomy 与标注说明 |
| 第 5–7 天 | 代表帧试标：目标 prompt、可见 mask、接触面、三项标签；双人复核 | 已复核小样本集、争议案例清单 |
| 第 8–10 天 | 冻结划分与模块输入输出；评估候选分割器和规则/分类器的可运行性 | 基线配置、评估协议、可复现命令与未解决问题 |

**当前进度**：历史审计记录显示 245 对 RGB-D 可读且配对；材质公开数据 ResNet-18 验证 Accuracy 75.20%、Macro-F1 0.7480。当前工作区只有 `data/enterprise` 模板，没有企业原始图像、实例 mask 或现场完整真值，因此不能据此报告现场分割、几何或端到端成绩。

## 2. 模块候选与第一版实验

| 模块 | 第一个可复现基线 | 待比较候选 | 数据前提 |
| --- | --- | --- | --- |
| Prompt → mask | 选一个可提示分割模型，固定模型版本、提示转换规则与阈值；同时保留人工 mask 上界实验 | RGB-D 深度边界后处理、其他提示分割器 | prompt 到实例真值、人工 mask、运行许可与显存测试 |
| Geometry | 基于 mask 的轮廓/长宽比、RGB 外观，加有效深度占比与相对深度起伏；小样本先做可解释规则 | 轻量分类头或视觉语言模型 | 六类复核标签；深度配准确认后才做 RGB-D 实验 |
| Material | 复用现有五类 ResNet-18，对经复核接触面 ROI 推理 | 现场数据微调、mask 限定的 ROI | 接触面真值；复合材质和 unknown 单独统计 |
| Deformability | 基于人工确认类别/可见证据的简单规则，不能判定则 `uncertain` | 有受力/抓取反馈后训练属性模型 | 明确标签依据，避免把几何或材质当作力学真值 |
| JSON | 固定 [标注 schema](annotation_schema_v1.md) 的字段和失败状态，保存 mask 文件 | 后续 API 服务 | 跨模块 ID、路径和坐标一致 |

先运行 **oracle mask**（用人工真值 mask）评估后续分类，确定分割误差之外的上限；再运行自动 mask 的端到端流程。RGB-only 与 RGB-D 应使用相同数据划分、同一后续模型与评价口径。深度未知或未配准时 RGB-D 路线暂停，避免伪对照。

## 3. 数据划分与指标

- 企业数据按 SKU 分组，同时保证同一源帧派生样本、近重复连续帧和采集批次不跨 train/validation/test。先冻结保留测试集，再调模型；SKU 缺失时记为划分风险，不宣称跨 SKU 泛化。
- 分割：按匹配实例计算 mask IoU，报告 IoU@0.5 成功率、平均 IoU、漏检/误检；多实例场景可补充 AP。prompt 无目标样本单列误检率。
- Geometry、Material、Deformability：仅在对应 `confirmed` 真值上报告每类 precision/recall/F1、macro-F1 与混淆矩阵，同时报告 `unknown/uncertain` 覆盖率。Material 的公开 MINC 指标与企业现场指标分开。
- 端到端：prompt 匹配成功率、所有必需字段均正确的实例比例、JSON 有效率、各模块与整帧延迟；注明 CPU/GPU、输入尺寸、模型版本。因 `uncertain` 合理拒判而未给类别的样本单独统计，不混作正确分类。
- 结果附按几何/材质、SKU、深度缺失、遮挡和反光分组的误差样例。阈值只在 validation 上确定，测试集只用于冻结方案后的最终报告。

## 4. 进入 Week 3–4 MVP 的门槛

至少有可访问的 RGB-D 输入与已复核 prompt-mask 对应样本；标签边界已审定；能读取标注、检查 mask/坐标一致性并运行模块评估；深度元数据已确认，或明确采用 RGB-only MVP 并将深度分支列为待接入。MVP 最终须对未见过的新帧输出实例 mask、几何、材质、形变状态和 JSON，而不是只对人工裁剪 ROI 运行材质分类。
