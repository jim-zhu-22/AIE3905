# 可扩展感知应用阶段成果

本阶段在分割 API 的基础上，完成了一个本机浏览器应用，形成“输入图片或已有成果—创建任务—查看实例—导出结果”的操作流程。

主要成果如下：

1. 完成工作台、任务记录、模块接入和使用说明页面，支持上传 RGB 与可选深度图、导入同学的分割 ZIP、查看分割叠加图和每实例 mask，并下载统一 JSON、报告和完整结果包。
2. 增加后台任务和本地历史记录。每次处理有独立编号，可查询进度、重新查看结果；单个属性模块失败时，保留其他有效结果并说明原因。
3. 提供可扩展模块接入方式，兼容 Python 模块、独立命令行程序和 HTTP 服务。已按仓库现有分割、材质程序提供适配入口，后续可通过配置增加几何、物理属性等模块。
4. 保留输入检查、请求追踪、结果校验和失败回滚，并将已有样例与新图片推理明确区分，避免把读取旧结果作为新的模型推理成果。

验证方面，40 项代码测试通过，当前环境与全新依赖环境均完成了任务创建、34 个实例文件访问、模块缺失提示和完整结果包下载的实际接口验证；浏览器已验证样例处理、历史回查与实例搜索。

当前已具备应用和模块扩展框架。真实模型推理、材质权重联调和 Docker 运行仍需在对应环境验证；深度像素处理及尚未交付的算法不计入已完成成果。
