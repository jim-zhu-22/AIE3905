## 已知限制与下一步

本次是真实模型功能联调，不是独立精度测试。四帧中前三帧参与过现有材质权重训练，最后一帧是此前的相邻帧留出集；SKU 未确认，不能声称跨 SKU 泛化。没有增加人工真值，也没有将自动输出写入训练集。

人工查看最后一帧叠加图，设备侧挡板被识别为 carton/packet，说明存在背景误检。下一轮应在独立验证集上比较更聚焦的 Prompt 和限定输送带区域，报告对漏检和误检的共同影响；本次没有为该测试帧单独调阈值。

深度单位和配准标记均为 unconfirmed，因此真实样本只运行 RGB 路径。深度统计已通过合成输入测试；三维几何类别、尺寸、质量、摩擦系数仍需相机标定、标签或物理测量，当前输出 null/unverified。材质 unknown 拒识、概率校准和 bbox/masked 精度对照尚未验收。
