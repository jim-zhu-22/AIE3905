**MirrorSpace × AIE3905**

面向仓储机器人抓取的 RGB 表面材质识别项目。基于 MINC-2500 与企业实拍数据双线开展模型训练、迁移对比和跨 SKU 泛化评估，计划提供材质识别模型、推理 API 与可视化 Demo。

**当前状态：项目规划阶段。** 本 README 根据《项目流程》整理；训练代码、模型权重、API 和 Demo 尚未在本仓库交付。下文描述目标方案与实施计划，暂不提供未经验证的安装和运行命令，也不报告尚未获得的实验成绩。

## 研究目标

输入物体或抓取区域的 RGB 图像，识别实际可见的接触表面材质，为后续抓取策略研究提供感知信息。

核心研究问题是：**模型是否依赖包装、文字和背景等外观线索，还是学习到了能够跨商品迁移的材质相关特征？**

项目将以训练中未出现的新 SKU 为主要测试对象，并结合整物体与局部 ROI、包装文字和背景干扰实验分析模型的判断依据。跨 SKU 表现可以提供泛化证据，但不能单独证明模型理解了真实物理材质。

## 识别范围

| 标签 | 材质 | 标注口径 |
| --- | --- | --- |
| `paper` | 纸质 | 以接触区域为准，不将所有纸盒外表面默认标为纸质 |
| `plastic` | 塑料 | 包括能够确认的塑料表面，不推断具体聚合物成分 |
| `metal` | 金属 | 涂层、贴纸等覆盖区域需按实际表面判断 |
| `wood` | 木材 | 根据可见接触表面标注 |
| `fabric` | 织物 | 不进一步推断是否为纯棉 |

初期 Demo 完成五类分类；后续增加 `unknown` 拒识状态。`unknown` 表示模型不接受该次预测，不等同于训练了覆盖所有其他材质的第六类。“其他”是否作为独立训练类别，将在标签规范中明确。

复合、覆膜或仅凭图像难以确认的区域应标为待核实。模型分数不等于真实正确概率；材质类别也不直接等于吸盘参数或抓取成功率。

## 双线技术路线

| 数据线 | 主要用途 | 与另一条线的关系 |
| --- | --- | --- |
| 公开数据线 | 使用 MINC-2500 建立基线，验证训练与评估流程 | 提供材质预适配权重及迁移对照 |
| 企业数据线 | 使用仓储实拍数据建立现场模型，验证未见 SKU 表现 | 检验公开数据的迁移价值，支撑最终应用评价 |

两条线共用训练、评估、预处理和推理代码，通过数据清单与配置区分。Demo 计划支持切换模型权重，并展示模型版本和训练来源。

```text
MINC-2500 ──→ 公开数据基线 ───────────┐
                                    ├─→ 迁移对比与调优
企业实拍数据 ──→ 企业数据基线 ────────┘
                                             ↓
                                  未见 SKU 与外观干扰评估
                                             ↓
                                  材质识别 API 与可视化 Demo
```

自动检测、材质分割和完整抓取规划不作为初期交付前提。ROI 优先来自现有标注、物体区域接口或人工选取。

## 数据集

### MINC-2500

- Hugging Face：[mcimpoi/minc-2500_split_1](https://huggingface.co/datasets/mcimpoi/minc-2500_split_1)
- 原始项目：[Materials in Context Database](https://opensurfaces.cs.cornell.edu/publications/minc/)
- 完整数据包含 23 类、57,500 张 362×362 图像块，主要字段为 `image` 和 `label`。
- 初期筛选上述五类，共 12,500 张，保留数据集已有的训练、验证与测试划分。
- 从数据集读取原始类别名称，再映射为项目标签；不直接沿用原始 23 类的整数编号作为五类输出编号。

公开数据用于基线和迁移研究，不能替代企业现场测试。使用和分发时遵循数据集与原始图像对应的许可条款。

### 企业实拍数据

由合作方提供，复用现有的模型初标与人工调整流程。接入时检查标签是否描述接触表面材质，以及是否具备 ROI、SKU 和采集批次信息。企业数据不默认作为公开仓库的组成部分。

数据清单计划记录：样本编号、图像路径、材质标签、数据来源、SKU、采集批次、原图编号、ROI、集合归属和审核状态。

划分与质检规则：

- 第一周起按 SKU 隔离训练、验证和最终测试集。
- 同一 SKU 的图片及同一视频的近重复帧不跨集合。
- 自动初标需人工审核；不确定样本进入待核实集合。
- 模型选择与阈值调整只使用验证集，最终测试集不参与调参。
- 两条线统一标签语义；缺失类别明确标记，比较时报告共同类别及实际覆盖。
- 早期现场探查与最终测试分开；若没有可靠 SKU 信息，不将结果称为严格跨 SKU 测试。

## 模型选择

**初期推荐：ImageNet 预训练 ResNet-18。** 替换为五类分类头，先训练分类层，再以较小学习率微调网络。固定 224×224 输入及预处理，根据验证集 Macro-F1 选择权重。

| 模型 | 差异与优势 | 本项目定位 |
| --- | --- | --- |
| ResNet-18 | 经典残差卷积网络，结构直接，便于微调和排错 | 前两周双线基线 |
| EfficientNet-B0 | 参数与理论计算量较小，适合比较识别效果与部署成本 | 第五周优先对比 |
| MobileNetV3-Large | 面向移动端的轻量网络 | 有明确 CPU 或边缘部署需求时加入 |
| ConvNeXt-Tiny | 更大容量的现代卷积网络，训练推理成本较高 | 算力与时间允许时作为精度候选 |
| DINOv2 ViT-S/14＋分类头 | 自监督预训练特征，可冻结主干，仅训练分类器 | 作为跨 SKU 迁移研究的可选方案 |

以上是选型建议，不是本项目实测排名。理论计算量不等于实际延迟；所有模型都可能依赖外观线索，最终应通过相同划分和评价协议比较。

计划技术栈：Python、PyTorch、TorchVision、FastAPI、Gradio。具体依赖版本将在实现与环境验证后固定。

## 实验设计

### 三种训练路径

| 路径 | 训练方式 | 研究问题 |
| --- | --- | --- |
| 公开模型直接迁移 | ImageNet → MINC → 现场推理 | 公开材质数据训练的模型能否直接用于仓储？ |
| 仅企业数据微调 | ImageNet → 企业训练集 → 现场推理 | 仅使用企业数据能达到什么水平？ |
| 公开加企业数据微调 | ImageNet → MINC → 企业训练集 → 现场推理 | 材质预适配是否改善现场识别和泛化？ |

三条路径在验证集上调参，第八周使用同一独立企业测试集比较。控制网络结构、标签和评价协议，记录额外训练预算，必要时增加等预算对照。

### 材质与外观线索分析

- **未见 SKU：**衡量对新商品的迁移能力，报告各类及各 SKU 表现。
- **整物体与局部 ROI：**对相同源样本比较不同输入区域，分析商品整体外观的影响。
- **文字与背景干扰：**在材质标签不变的前提下改变非材质线索，区分线索依赖与人工扰动造成的分布变化。
- **未知材质与低可信度输入：**独立收集范围外及难判样本，评价拒识效果。未知 SKU 不等于未知材质。

主要指标包括 Accuracy、Macro-F1、各类 Precision／Recall／F1、混淆矩阵、推理耗时；拒识实验同时报告未知检出率、已知误拒率、保留比例与保留样本错误率。

公开与现场结果分开报告。显著性图可作为辅助分析，但不单独作为模型理解材质的证据。

## 十周计划

| 周次 | 公开数据线 | 企业数据线 | 共同成果 |
| --- | --- | --- | --- |
| 第1周 | 数据筛选、ResNet-18 首轮训练 | 标注适配、ROI 与 SKU 检查、测试集隔离 | 共用数据、训练与评估接口 |
| 第2周 | 公开基线选模与测试 | 条件具备时训练现场基线，仅用验证集比较 | **M1：双线验证 Demo** |
| 第3周 | 固定公开模型与迁移起点 | 完善标注规范，固定现场数据 v1 | 三路径实验与统一协议 |
| 第4周 | 建立公开直迁及公开加现场微调方案 | 完善仅现场微调方案 | **M2：迁移基线与 API 骨架** |
| 第5周 | 支持 EfficientNet-B0 对比 | 有限调优与训练数据补充 | 模型比较、迁移收益分析 |
| 第6周 | 整理必要实验，可选 DINOv2 | ROI、光照、文字背景及拒识实验 | **M3：外观依赖研究结果** |
| 第7周 | 冻结公开基线及记录 | 冻结现场模型、预处理、阈值 | **M4：方案冻结** |
| 第8周 | 提供冻结模型参加统一现场测试 | 未见 SKU、干扰与未知输入测试 | **M5：独立实验及 API 测试** |
| 第9周 | 整理方法与迁移实验材料 | 数据规范与可选吸盘验证 | 交付候选版、报告与视频 |
| 第10周 | 核对复现与引用 | 核对应用结论与局限 | **M6：完整交付与验收** |

前两周先完成真实模型预测闭环，不承诺已具备完整未知材质识别能力。如果企业标签尚未就绪，应明确现场模型未完成；公开模型及数据读取展示不能被表述为双模型验收通过。

第七周冻结后如必须修改模型、阈值或预处理，应记录版本和原因。用于指导修改的测试数据不再视为未接触测试集。

## API 与 Demo 规划

计划提供 `POST /predict`，接收图像和可选 ROI。ROI 坐标基于原图，单位为像素。响应拟包含预测类别、五类分数、`accepted` 或 `unknown` 状态、模型版本及服务端处理耗时。

该接口尚未实现。无效图像、越界 ROI 和模型未就绪等情况需提供明确错误；拒识阈值根据验证集确定。

Demo 计划支持图片上传、ROI 选择、公开与现场模型切换、类别分数展示及人工复核提示。早期版本可先接收已裁剪 ROI，再补齐框选交互。
