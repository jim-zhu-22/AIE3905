# 材质 ROI 标注规范（第一版）

## 标注对象

标注机器人实际可能接触的**可见外表面**，不要根据商品名称、包装内物或印刷图案推断基材。每个样本应对应单一接触面 ROI；混合材质或遮挡区域需重新裁剪或标记待复核。

| 项目标签 | 含义与边界 |
| --- | --- |
| `paper` | 裸露纸张、纸板、纸壳。塑料覆膜表面按实际接触层标注，不能仅因下层是纸而标为纸。 |
| `plastic` | 可见塑料包装、薄膜、瓶体或涂覆层。印有木纹、金属色的塑料仍按接触层标注。 |
| `metal` | 可见金属接触面。金属色印刷或镀铝塑料需人工核实，不能只凭颜色判定。 |
| `wood` | 可见木材接触面；仿木纹塑料或纸板不算木材。 |
| `fabric` | 纺织/织物接触面，不推断为纯棉。 |

无法从图像与现场信息确认时记录为待复核，不强行放入五类训练集。`unknown` 在第一阶段是拒识状态，不等同于一种已训练的真实材质类别。

## 记录与划分

清单字段模板在 `data/enterprise/manifest.template.csv`。至少保留样本 ID、图像路径、接触面标签、SKU、采集批次、原图 ID 和人工确认状态；未裁剪图像还要记录 ROI 坐标。标注工具的模型预标注必须经人工确认，训练清单中的 `annotation_status` 写为 `confirmed`。

同一 SKU 只进入训练、验证或最终测试的其中一个集合。同一原图派生的多个 ROI，以及连续拍摄的近重复帧，应随 SKU 放入同一集合。最终测试 SKU 在模型调参前固定；公开 MINC 数据没有 SKU 字段，不能替代这项现场测试。

至少抽查每类的边界案例，记录争议标签、复核结论及版本日期。对于覆膜、复合包装和强反光表面，应保留人工审核理由，后续作为误差分析样例。
