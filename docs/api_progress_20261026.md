5. 提供演示页面、OpenAPI 接口定义、交互式文档、PowerShell 启动脚本和调用示例。

7. 冻结 16 个运行依赖，分离图像、结构、存储和 HTTP 逻辑，便于复现与维护。
8. 编写 Dockerfile 和 Compose 配置，提供样例目录挂载方式；本机没有 Docker，尚未构建或运行验证。
