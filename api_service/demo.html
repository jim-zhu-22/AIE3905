演示说明
几分钟，看懂图片分析的全过程
上传现场图片，启动分析，再按步骤查看真实结果。
开始分析 →




1
从上传图片开始
在“流程演示”选择一张现场图片，点击“开始分析”。页面显示真实任务进度，完成后自动展示结果；也可以回看已有记录。


2
跟着一个物体看
用物体下拉框切换目标，各步骤会跟随同一个物体，便于对照它在原图中的轮廓、特写和材质候选。


3
理解“识别物体”
系统把画面中的目标逐个圈出来，标出各自的位置与轮廓。这一步在技术上叫“检测与分割”。


4
交接给下游系统
最后一步展示目标编号、类别、像素位置、轮廓与材质预测，导出 JSON 后可供机器臂任务规划模块读取。评分反映模型倾向，不等于实际准确率。




目前能展示什么？
物体位置与轮廓、物体特写、材质候选，以及可下载的结构化结果。深度信息已保留，物理尺寸和几何属性尚未计算。
点击“开始分析”会调用本机模型；切换结果步骤不会重新推理。离线文件仅支持成果回看。流程到“汇总与导出”结束。
