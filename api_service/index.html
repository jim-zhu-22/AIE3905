HTTP 服务

查看简短成果报告 ↗
1

查看已有成果

在工作台选择已有分割包并生成任务，查看实例、mask 和报告。这里复用已有结果，不会重新运行模型。

2

处理新图片

配置模型环境和权重后，上传原始 RGB。可选上传深度图，应用会记录深度状态，不自动推断物理尺寸。

3

连接属性模块

在配置文件中注册材质、几何等模块。一个模块失败时，保留其他有效结果，并说明缺失原因。

4

导出与继续开发

下载统一 JSON、每实例 mask 和报告；任务记录支持再次查看。接入细节与可用接口见项目文档。

当前能力以“模块接入”页为准。真实模型推理与 Docker 运行需要在对应环境中另外验证。
